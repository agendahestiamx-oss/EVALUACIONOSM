¿Cómo funciona?
1. La Responsable OSMs crea la sesión y obtiene un código de 6 letras.
2. Comparte el código con Carmen y Contabilidad — cada una entra desde este mismo link.
3. Cada quien llena su sección. La Responsable ve el progreso en tiempo real.
4. Cuando las tres terminan, se genera el reporte PDF listo para entregar.
